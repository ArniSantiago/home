# Arni Santiago portfolio sites

This repository contains two independent static websites under one GitHub Pages project site.

- Main landing page: `index.html`
- Arni Design: `arni-design/index.html`
- Email Design Portfolio: `arni-portfolio/index.html`

For the repository named `home`, the URLs are:

- `https://arnisantiago.github.io/home/`
- `https://arnisantiago.github.io/home/arni-design/`
- `https://arnisantiago.github.io/home/arni-portfolio/`

In GitHub, set **Settings → Pages → Deploy from a branch → main → /(root)**. This repository includes `.nojekyll` because the sites are already built static files.

Because some original portfolio artwork files are larger than the GitHub web uploader limit, upload this folder using GitHub Desktop or Git from a computer rather than dragging the files into the browser.
